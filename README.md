# СИМАРГЛ — демонстрационная версия

[Открыть сайт](https://fedosoff-vc46.github.io/simargl-preview/)

Статическая версия для показа заказчику. Контактные данные уточняются. Индексация поисковыми системами отключена.

В этом репозитории находятся только файлы готового сайта. Шрифт Manrope распространяется по SIL OFL 1.1; текст лицензии — `fonts/OFL.txt`.
